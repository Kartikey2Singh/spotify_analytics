# Spotify Analytics

A browser-based dashboard for visualizing Spotify listening history. Import CSV or JSON files, or choose an extracted Spotify export folder. Listening history is stored in each visitor's browser and is not uploaded to a server.

## Run locally

Open `index.html` in a modern browser, choose a history file or folder, and click **Load Data**.

## GitHub Pages

Enable GitHub Pages in repository settings by choosing **Deploy from a branch**, then select `main` and `/(root)`. The site URL is `https://kartikey2singh.github.io/spotify_analytics/`.
