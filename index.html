How to download your Spotify data?
  1. Open the Spotify Account Privacy page and sign in.
  2. Go to Download your data, select Extended streaming history, and submit your request.
  3. When Spotify emails you, download and extract the ZIP file.
  4. Use Choose Folder to load the extracted export folder, or use Choose File to upload one CSV or JSON history file.
Note: Spotify normally provides exports in JSON format, not CSV. This dashboard supports both JSON and CSV files. Imported history is saved in this browser only; it is not uploaded to a server.
